Although I bought the domain BotDianGS DotCN, and bought it for ten years in one go, I still wasn't very satisfied with it. So I tried configuring Tencent Enterprise Mail, using this domain to run emails, and set it up as an SMTP server to send emails to prepare for the upcoming software system.

So far, the results are just average. The entire Tencent Enterprise Email registration process was very smooth, but disappointingly, information was lost on the front and back pages during registration, and the previously filled content was invisible, causing me to lag for twenty to thirty minutes. I had to wait until it was approved before trying again.

Of course, its configuration is also quite remarkable. In terms of configuration, it only has MX records and one Class C record, and unlike other email addresses, it doesn't need to parse TXT records or similar functions, which might cause conflicts with the browser system. It's amazing. Maybe choosing Alibaba or NetEase is the best solution.

Try running it first, because now you need to choose a stable SMTP service, which makes user registration, password recovery, and other aspects clearer. But Evo has a problem right now: it doesn't support receiving emails—the configured SMTP doesn't support receiving emails, so you have to set up a separate inbox or even just forward, but it really doesn't support receiving emails, which is quite frustrating.

Having something first, then excelling; bad things start with good results.
